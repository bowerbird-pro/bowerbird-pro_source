Context
분석 보고서에서 기능, UX, 데이터 처리 3개 영역에서 총 25개 이슈가 도출되었다.
이 계획은 긴급 → 높음 → 중간 → 낮음 순서로 6개 Phase에 걸쳐 전체 항목을 순차적으로 개선한다.
각 Phase는 이전 Phase의 결과에 의존하거나 독립적으로 수행 가능하도록 설계되었다.

Phase 1: 긴급 버그 수정 — 크래시 방지

장시간 로깅 시 브라우저 크래시를 유발하는 치명적 문제 2건 해결

1-1. Math.min/max 스택 오버플로 수정

파일: js/analysis/statistics.js
현재: Math.min(...data) / Math.max(...data) — 65K개 초과 시 크래시
변경: 루프 기반 min/max 계산으로 교체

javascriptlet min = Infinity, max = -Infinity;
for (let i = 0; i < data.length; i++) {
    if (data[i] < min) min = data[i];
    if (data[i] > max) max = data[i];
}
1-2. csvData 메모리 고갈 방지

파일: js/main.js, js/utils/helpers.js
현재: csvData.push() 무한 성장
변경:

csvData에 최대 행 수 제한 (MAX_CSV_ROWS = 500,000)
한계 도달 시 자동으로 CSV 파일 분할 저장 (chunk export)
사용자에게 알림 표시



검증

10만 개 이상의 데이터 포인트를 시뮬레이션하여 크래시 없이 동작 확인
메모리 사용량 모니터링 (DevTools Performance 탭)
